AVANTIX LABS - LOGO KIT (Sculpted Ivory, Option D: The Keystone)

WHICH FILE TO USE
- Website header, documents, light backgrounds ...... avantix-labs-logo-primary
- Dark backgrounds (espresso, photos, dark mode) .... avantix-labs-logo-reversed
- One-colour printing, stamps, engraving ............ avantix-labs-logo-black / -white
- Square spaces (social posts, packaging) ........... avantix-labs-logo-stacked-*
- Small spaces where the name already appears ....... avantix-labs-mark-*
- Social media profile picture ...................... Icons/social-profile-ivory-1024.png
- Website favicon .................................... Icons/favicon.ico (+ favicon.svg, apple-touch-icon-180.png)

SVG = vector, use wherever possible (website, print). Text is converted to outlines, so no font install is needed.
PNG = transparent background, high resolution.

COLOURS

Bronze        #8A4B2A   RGB 138 75 42     (accent on light backgrounds)
Ivory         #F3F0E8   RGB 243 240 232   (logo on dark backgrounds, page background)
Light bronze  #C4895C   RGB 196 137 92    (accent on dark backgrounds only)
Limestone     #E4DED2   RGB 228 222 210   (surfaces)
Stone         #746F64   RGB 116 111 100   (secondary text)

FONTS (free for commercial use, Google Fonts)
Wordmark: Manrope Medium (AVANTIX) and Manrope SemiBold (LABS)
Website headings: Instrument Serif  |  Body text: Manrope

RULES
- Keep clear space around the logo equal to the height of the bronze crossbar x 4 (roughly the height of the letter A in AVANTIX).
- Minimum width: horizontal logo 140 px on screen / 35 mm in print. Below that, use the mark only.
- Do not stretch, rotate, recolour, add shadows or outlines, or place on busy photos without a solid panel.
